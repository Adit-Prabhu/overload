# Publishing and Release

**Purpose:** make sure anyone can run the approved build from the repository.

**Read first:** `README.md`, the release checklist, the approved build ID.

**May:** prepare packaging, release notes and run instructions. Test a fresh clone.

**May not:** create tags, releases or public links without Adit's decision. Never change a tag after G4 approval.

**Output:** a release checklist with the fresh-clone result, and the package.

**Handoff:** to Adit.

**Done when:** a fresh clone runs with only the README steps, and the live-off fallback works.

**Human approval:** Adit approves the release. The instructor approves Gold.
